# استيراد المقررات: CSV / XLSX (نموذج أولي)

## CSV الصادر من خطة رايات

يعتمد **مقرر/اسم المقرر/الفصل التدريبي/مح/عم/تم**؛ ويستخدم عمود «الفصل التدريبي» الأقرب للمقرر إن تكرر اسم العمود في التصدير. يمثّل «تم» مع الساعات النظرية **مؤقتًا**، ويصدر تنبيهًا لمراجعة متطلباتها الفعلية قبل جدولة المقرر. يتحقق من أن «س» = مح + عم + تم إذا ظهر العمود.

- يستبعد «المشروع» بناءً على قرار صاحب المشروع.
- يحتفظ بالتدريب التعاوني خارج جدول المحاضرات الأسبوعية إذا لم تكن له ساعات اتصال.
- لا يستنبط عدد متدربين من الخطة: `demand = 0` حتى يصل تقرير تسجيل منفصل.
- كل مقرر يبدأ بنمط `ONSITE` و`eligibleModes:["ONSITE"]`، ولا تعتمد الأنماط الأخرى آليًا.
- لا يستورد أسماء المتدربين أو أرقامهم.

```bash
npm run import:csv -- "my-curriculum.csv" catalog.json
```

يمكن استخدام الواجهة المحلية أو API:

```bash
curl -X POST http://127.0.0.1:8787/api/v1/catalog/import-csv \
  -H 'Content-Type: text/csv; charset=utf-8' --data-binary @"my-curriculum.csv"
```

## استيراد Excel مباشرة من واجهة الويب (v0.3)

- افتح TPS محليًا على `http://127.0.0.1:8787`، ثم انقر **تحميل قالب Excel جاهز**.
- يحتوي القالب على 24 مقررًا من خطة قسم تقنيات الأعمال المكتبية للفصل 144720. املأ عمود **الطلب المتوقع** في ورقة **المقررات** مع مراجعة رمز المقرر والمستوى وساعات النظري/العملي.
- أعد رفع الملف في حقل **رفع بيانات المقررات (Excel / CSV)**، ثم اضغط **قراءة وتحقق من الملف**.
- يستخدم التطبيق `POST /api/v1/catalog/import-xlsx` بمحتوى XLSX ثنائي، ويشغل محول Python المحلي بصورة مقيدة. لا يرفع الملف إلى GitHub ولا يخزنه دائمًا؛ يزيل الملف المؤقت بعد التحليل.
- يستورد المدخلات فقط، ولا يكوّن جدولًا كاملاً بدون بيانات المدربين والقاعات. لا تُستخدم أنماط التدريب الاختيارية إلا بتفويض صريح.
- الواجهة **للتطوير المحلي فقط** إلى حين إضافة تسجيل دخول وصلاحيات وتدقيق للسجلات.
- يتطلب جهاز التشغيل `Python 3` ومكتبة `openpyxl`. يمكن تحديد المسار عبر `TPS_PYTHON`.
- الحد الافتراضي لطلب HTTP هو 5 MiB. يوجد فحص إضافي للضغط وعدد عناصر ZIP وعدد صفوف ورقة Excel.

```bash
curl -X POST http://127.0.0.1:8787/api/v1/catalog/import-xlsx \
  -H 'Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet' \
  --data-binary @TPS_Course_Demand_144720.xlsx
```

## XLSX المستخدم في تخطيط القسم

استيراد اختياري عبر أداة Python محلية (تحتاج openpyxl). تقرأ فقط الأعمدة: رمز المقرر، اسم المقرر، المستوى، الطلب المتوقع، نظري + تمارين، عملي. **لا تنقل نمط التدريب المحدد في الملف إلى النظام تلقائيًا**، لأن أهلية المقرر تتطلب اعتمادًا مستقلًا.

```bash
python -m pip install openpyxl==3.1.5
python scripts/import_xlsx.py "my-planning.xlsx" --out catalog.json
```

تقرأ الأداة الخلايا **دون استخدام القيم المخزنة للصيغ** (`data_only=False`) وترفض الصيغ في حقول البيانات بدل تقييمها أو الوثوق بمخرجاتها القديمة. يعرض المستورد أخطاء الصفوف غير المكتملة أو التكرارات بدل حذفها صامتًا.

## مراجعة النتائج

المخرجات `tps.catalog.v1` هي كتالوج مقررات، **وليست جدولًا مكتملًا**. يجب تزويد بيانات المدربين والقاعات، والتحقق من أعداد التسجيل، ثم تحويله إلى `PlanRequest` بعد مراجعة المسؤول. لا ترفع ملفات ذات بيانات شخصية إلى GitHub.
